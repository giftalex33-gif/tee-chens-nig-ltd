# Tee Chens Nig Ltd — refreshed static storefront

This repo now includes a cleaner, more functional static storefront for the Tee Chens project.

## Run locally
Open `index.html` in a browser, or serve the folder with a simple local web server.

## Included improvements
- Better responsive styling
- Working local cart, wishlist and comparison logic
- Product catalogue with search and filters
- Cleaner product detail flow
- Quote-request and contact forms that save locally
- Stronger storefront layout and navigation

## Notes
This is still a front-end prototype, so all order and enquiry data is stored in the browser local storage only.
